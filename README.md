# Cheqzo

Desktop web app for renovation progress, money, and approvals. Phases 0–3 are in place: foundations, auth and the app shell, the portfolio, and project creation. Later screens are placeholders.

The spec is `docs/CHEQZO_BUILD_GUIDE.md`.

## Setup

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run test
npm run build
```
